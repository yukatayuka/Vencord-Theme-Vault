## ✉ Inquiries & theme requests

Have a question, found a bug, or want to request a theme? **[Open an issue](../../issues/new)**.
Please include the theme name and a clear description of your question, request,
or the steps to reproduce a bug.

## ↓ Install a theme

1. Download the `.theme.css` file from the theme folder.
2. Move it into Vencord's themes folder (usually `%AppData%\Vencord\themes` on Windows).
3. In Discord, open **User Settings → Vencord → Themes**, then reload themes if needed.
4. Enable the theme.

Alternatively, paste the CSS into Vencord's **Settings → Vencord → Themes → Edit QuickCSS**.
